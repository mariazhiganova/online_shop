# Проект "Интернет-магазин"

## Описание

В проекте реализовано ядро для интернет-магазина без интерфейса.

### Описание модулей

В пакете **src** находятся модули с основным функциональным кодом:

В модуле **product** находится класс _Product_ для представления товаров. Класс имеет два родительских класса _BaseProduct_ и _PrintMixin_. При попытке добавить товар с кол-вом 0 вызовет исключение ValueError.
В модуле **category** находится класс _Category_ для представления категорий и их подсчета, а также подсчета кол-ва
товаров в категории. Имеет метод подсчета средней стоимости товаров категории. При отсутствии товаров выведет 0.
В модуле **utils** находятся вспомогательные функции:

- _read_json_ для чтения json-файлов
- _create_objects_from_json_ для создания объектов класса.

В модуле _product_iterator_ реализован итератор, который перебирает все товары категории. Возвращает их по одному.

В модуле **smartphone_category** описан класс _Smartphone_, наследник класса Product. Описывает категорию товаров Смартфоны. Дополнен указанием модели, памяти и цвета.
В модуле **lawngrass_category** описан класс _Lawngrass_, наследник класса Product. Описывает категорию товаров Трава газонная. Дополнен указанием страны-производителя, срока прорастания и цвета.

В модуле **settings** находятся пути к корневой директории проекта и к необходимым файлам.

В модуле **base_product** описан абстрактный класс _BaseProduct_, содержащий абстрактный метод класса для добавления новых продуктов.

В модуле **print_mixin** описан класс-миксин, позволяющий печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

В модуле **exceptions** создано кастомное исключение, выводящее сообщение о добавлении товара в категорию.

### Установка

1. Клонируйте репозиторий

```commandline
git clone git@github.com:mariazhiganova/online_shop.git

```

2. Установите зависимости

```commandline
poetry install
```

### Тестирование

Проект покрыт юнит-тестами Pytest. Они располагаются в пакете **tests**

Чтобы запустить тесты с оценкой покрытия выполните команду:

```commandline
poetry run pytest --cov
```

Чтобы сгенерировать отчет о покрытии в HTML-формате, где src — пакет c модулями, которые тестируем.
Отчет будет сгенерирован в папке htmlcov и храниться в файле с названием index.html.

```commandline
pytest --cov=src --cov-report=html
```
